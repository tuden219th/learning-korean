# 흔한 동사: 하다, 가다, 오다, 있다, 없다

## 목표 (Mục Tiêu / Learning Objectives)

After this lesson, you will:
- Know the five most essential verbs in Korean
- Conjugate them correctly in -아요/-어요 form
- Use them productively in simple sentences

## Tiếng Việt So Sánh (Vietnamese Comparison)

**Vietnamese:** "I do" uses verb 'làm'
- Tôi làm bài tập. (I do homework.)

**Korean:** "I do" uses 하다, which is incredibly flexible
- 나는 공부를 해요. (I do studying = I study.)
- 나는 숙제를 해요. (I do homework.)
- 나는 밥을 해요. (I do rice = I cook rice.)

The verb **하다** is perhaps the most productive verb in Korean.

## Năm Động Từ Thiết Yếu (Five Essential Verbs)

### 1. 하다 (do/make) → 해요
```
Used for: general actions, making things, doing activities

Examples:
공부하다 → 공부해요 (study)
숙제하다 → 숙제해요 (do homework)
밥하다 → 밥해요 (cook rice)
```

### 2. 가다 (go) → 가요
```
Used for: movement toward a destination

Examples:
학교에 가다 → 학교에 가요 (go to school)
집에 가다 → 집에 가요 (go home)
한국에 가다 → 한국에 가요 (go to Korea)
```

### 3. 오다 (come) → 와요 [IRREGULAR!]
```
Used for: movement toward the speaker

Examples:
학교에 오다 → 학교에 와요 (come to school)
집에 오다 → 집에 와요 (come home)
지금 오다 → 지금 와요 (coming now)
```

### 4. 있다 (exist/have/be) → 있어요
```
Used for: possession, existence, location, being somewhere

Examples:
나는 책이 있어요. (I have a book.)
고양이가 있어요. (There's a cat.)
나는 집에 있어요. (I am at home.)
```

### 5. 없다 (not exist/don't have) → 없어요
```
Used for: lack, absence, negation by property

Examples:
나는 책이 없어요. (I don't have a book.)
돈이 없어요. (I don't have money.)
시간이 없어요. (I don't have time.)
```

## 문법 패턴 (Grammar Patterns)

### Pattern 1: 하다 with noun objects
```
Subject + 는/가 + Noun + 을/를 + 해요

나는 숙제를 해요.
(I do homework.)

우리는 공부를 해요.
(We study.)
```

### Pattern 2: 가다/오다 with location
```
Subject + 는/가 + Location + 에 + 가/와요

나는 학교에 가요.
(I go to school.)

친구가 집에 와요.
(A friend comes to my home.)
```

### Pattern 3: 있다/없다 with subject + object
```
Subject + 는 + Object + 이/가 + 있/없어요

나는 책이 있어요.
(I have a book.)

우리는 시간이 없어요.
(We don't have time.)
```

## 예제 (Examples)

**Example 1: Using 하다**
```
나는 한국어를 공부해요.
(I study Korean.)

나 = I
는 = topic marker
한국어 = Korean language
를 = object marker (ends in vowel)
공부하다 = study (하다 + object)
공부해요 = conjugated form
```

**Example 2: Using 가다 and 오다**
```
나는 학교에 가요.
(I go to school.)

친구는 내 집에 와요.
(My friend comes to my house.)

学校に = to school (가다)
내 집에 = to my house (오다, from speaker's perspective)
```

**Example 3: Using 있다**
```
나는 형이 있어요.
(I have an older brother.)

가방에 책이 있어요.
(There's a book in the backpack.)
```

**Example 4: Using 없다**
```
나는 돈이 없어요.
(I don't have money.)

학교에 선생님이 없어요.
(There's no teacher at school [meaning: the teacher isn't there].)
```

## 흔한 실수 (Common Errors)

❌ **Mistake 1: Confusing 가다 and 오다**
- **WRONG:** 나는 학교에 와요. (implies I go to school and return here)
- **CORRECT:** 나는 학교에 가요. (I go to school, away from here)

❌ **Mistake 2: Using 있다 as simple "be"**
- **WRONG:** 나는 있어요 (sounds strange, like "I exist")
- **CORRECT:** 나는 집에 있어요 (I am at home - with location)

❌ **Mistake 3: Word order in 있다/없다 sentences**
- **WRONG:** 나는 책을 있어요 (using 을/를 instead of 이/가)
- **CORRECT:** 나는 책이 있어요 (using 이/가 for the object)

## 요약 (Summary)

These five verbs are the **foundation of Korean conversation**:
- **하다** = do/make (most productive)
- **가다** = go (away from speaker)
- **오다** = come (toward speaker)
- **있다** = have/exist (possession, location)
- **없다** = not have/don't exist (lack)

With these verbs and the particles you've learned (이/가, 을/를, 에/에서), you can create hundreds of simple Korean sentences.
