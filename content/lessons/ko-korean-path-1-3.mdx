# Vị Trí & Hướng Hạt: 에 / 에서

## 목표 (Mục Tiêu / Learning Objectives)

After this lesson, you will:
- Distinguish between **에** (static location/destination) and **에서** (location of action)
- Use both particles correctly in sentences
- Avoid the most common Vietnamese learner error (confusing the two)

## Tiếng Việt So Sánh (Vietnamese Comparison)

**Vietnamese:** Uses word order or prepositions
- Tôi ở nhà. (I stay at home.)
- Tôi đi đến trường. (I go to school.)

**Korean:** Uses 에 and 에서 differently
- 나는 **집에** 있어요. (I am at home [static].)
- 나는 **학교에서** 공부해요. (I study at school [action].)

**This distinction is critical.** Many Vietnamese learners use 에 for both, which is incorrect.

## Khái Niệm (The Concept)

Two location particles with **completely different functions**:

### 에 (destination or static location)
Used when:
- Destination of movement (going TO)
- Static position (being AT)
```
학교에 가요. (Go to school.)
집에 있어요. (Am at home.)
```

### 에서 (location of action)
Used when:
- An action happens at that location
```
학교에서 공부해요. (Study at school.)
카페에서 커피를 마셔요. (Drink coffee at a café.)
```

## 퀴즈로 理解 (Quiz-Based Understanding)

**Question: 나는 학교에 가요 vs 나는 학교에서 공부해요**

- 학교에 가요 = "I go TO school" (destination) → 에
- 학교에서 공부해요 = "I study AT school" (action) → 에서

**The difference:** Is the location a destination or an action location?

## 규칙 (Rules)

**Rule 1: Movement toward a place = 에**
```
집에 간다 = Go home
학교에 간다 = Go to school
한국에 간다 = Go to Korea
```

**Rule 2: Staying/being at a place = 에**
```
집에 있다 = Be at home
학교에 있다 = Be at school
```

**Rule 3: Action happening at a place = 에서**
```
집에서 먹다 = Eat at home
학교에서 공부하다 = Study at school
카페에서 마시다 = Drink at a café
```

**Rule 4: Physical location (not action-based) = 에**
```
서울에 있어요 = Am in Seoul (static)
한국에 살아요 = Live in Korea (static residence)
```

## 예제 (Examples)

**Example 1: Destination vs Action**
```
나는 학교에 가요.
(I go to school.)

나 = I
는 = topic particle
학교 = school
에 = destination marker (going TO)
가요 = go
```

```
나는 학교에서 공부해요.
(I study at school.)

나 = I
는 = topic particle
학교 = school
에서 = action location marker (action happens HERE)
공부해요 = study
```

**Example 2: Home scenarios**
```
집에 가요. (Go home.) — destination
집에 있어요. (I'm at home.) — static
집에서 먹어요. (I eat at home.) — action
```

**Example 3: Café scenario**
```
카페에 가요. (Go to the café.) — destination
카페에 있어요. (I'm at the café.) — static
카페에서 커피를 마셔요. (I drink coffee at the café.) — action
```

## 흔한 실수 (Common Errors for Vietnamese Learners)

❌ **Mistake 1: Using 에 for action locations**
- **WRONG:** 학교에 공부해요. (sounds incomplete)
- **CORRECT:** 학교에서 공부해요. (Study at school.)

❌ **Mistake 2: Using 에서 for destinations**
- **WRONG:** 학교에서 가요. (grammatically wrong)
- **CORRECT:** 학교에 가요. (Go to school.)

❌ **Mistake 3: Confusing static vs. action**
- **Think:** Is the person **going** somewhere? → 에
- **Think:** Is the person **doing** something somewhere? → 에서

## 요약 (Summary)

- **에** = destination or static location (going TO, being AT)
- **에서** = action location (doing something AT)

This distinction is **essential for Grade 10 exam success**. Examiners specifically test whether you understand the difference.
