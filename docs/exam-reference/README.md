## Curriculum Design Protocol

**Before any Korean Path curriculum is designed, the following must be completed:**

1. **OBTAIN** official exam materials (add to this folder)
2. **ANALYZE** each question systematically (create exam-analysis.md)
3. **EXTRACT** verified competency requirements from the real exam
4. **DISTINGUISH:**
   - A. VERIFIED FROM OFFICIAL EXAM (facts)
   - B. PEDAGOGICAL INFERENCE (reasonable assumptions based on Korean education standards)
   - C. UNKNOWN / NOT VERIFIED (gaps in evidence)
5. **DEFINE** two separate competency standards:
   - **EXAM READINESS:** Exactly what's needed to perform well on the entrance exam
   - **LANGUAGE DEVELOPMENT:** Additional Korean ability that is educationally valuable but not required for the exam
6. **PROPOSE** Korean Path curriculum map based on verified evidence
7. **SUBMIT** for four-reviewer validation
8. **IMPLEMENT** only after approval
