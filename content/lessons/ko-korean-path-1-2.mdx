# Tân Từ Hạt: 을/를

## 목표 (Mục Tiêu / Learning Objectives)

After this lesson, you will:
- Understand the **object marker (을/를)** shows who/what receives the action
- Use 을/를 correctly with different noun endings
- Write complete sentences with both subject (이/가) and object (을/를) markers

## Tiếng Việt So Sánh (Vietnamese Comparison)

**Vietnamese:** Uses word order
- Tôi ăn cơm. → (I eat rice) — word order shows I do it, rice receives it

**Korean:** Uses particles
- 나**가** 밥**을** 먹어요. → I [subject marker] rice [object marker] eat

The particles **이/가** (subject) and **을/를** (object) are both essential. You cannot skip either one.

## Khái Niệm (The Concept)

The **object marker (을/를)** marks the noun that **receives the action** of the verb.

### Structure
```
Subject + 이/가 + Object + 을/를 + Verb

나가 밥을 먹어요.
I eat rice.

나 = I (subject)
가 = subject marker
밥 = rice (object)
을 = object marker
먹어요 = eat
```

## Quy Tắc (Rules)

**Rule 1: Choose based on final sound**
- If noun ends in **consonant**: use **을**
  - 책을 읽어요 (Read a book.)
- If noun ends in **vowel**: use **를**
  - 밥을 먹어요 (Eat rice.) ← 밥 ends in consonant ㅂ
  - 물을 마셔요 (Drink water.) ← 물 ends in consonant ㄹ

**Rule 2: Common pattern**
```
책 (ends in consonant ㄱ) → 책을 읽어요
밥 (ends in consonant ㅂ) → 밥을 먹어요
사과 (ends in vowel ㅏ) → 사과를 먹어요
우유 (ends in vowel ㅠ) → 우유를 마셔요
```

## 예제 (Examples)

**Example 1: Eating something**
```
나는 밥을 먹어요.
I eat rice.

나 = I
는 = topic particle (different from 가, but often used)
밥 = rice
을 = object marker (밥 ends in consonant)
먹어요 = eat (casual polite)
```

**Example 2: Reading a book**
```
학생이 책을 읽어요.
A student reads a book.

학생 = student (ends in consonant ㄴ)
이 = subject marker
책 = book (ends in consonant ㄥ)
을 = object marker
읽어요 = read
```

**Example 3: Drinking water**
```
나는 물을 마셔요.
I drink water.

물 = water (ends in consonant ㄹ)
을 = object marker
마셔요 = drink
```

## 흔한 실수 (Common Errors for Vietnamese Learners)

❌ **Mistake 1: Using 이/가 for both subject and object**
- **WRONG:** 나가 밥이 먹어요. (nonsensical)
- **CORRECT:** 나가 밥을 먹어요. (I eat rice.)

❌ **Mistake 2: Forgetting the object marker**
- **WRONG:** 나는 밥 먹어요. (incomplete sounding to Korean speakers)
- **CORRECT:** 나는 밥을 먹어요.

❌ **Mistake 3: Wrong particle choice**
- **WRONG:** 책을 읽어요 should use 을 because 책 ends in consonant
- **CORRECT:** 책을 읽어요 ✓

## 요약 (Summary)

The **object marker (을/를)** is essential for marking what receives the action:
- Consonant ending: 을
- Vowel ending: 를

Every transitive verb (a verb that takes an object) requires this particle. Mastering subject (이/가) + object (을/를) gives you the foundation for 80% of Korean sentences.
