# 부정: 안

## 목표 (Mục Tiêu / Learning Objectives)

After this lesson, you will:
- Understand **안** as a negation marker meaning "don't/won't" (by choice)
- Use 안 + verb to express refusal or choice
- Distinguish 안 from 못 (which you'll learn in Lesson 1-8)

## Tiếng Việt So Sánh (Vietnamese Comparison)

**Vietnamese:** Negation particle 'không'
- Tôi không đi. (I don't go.) — simple negation

**Korean:** Two types of negation
- 나는 안 간다. (I won't go / I choose not to go.) — 안 (choice/refusal)
- 나는 못 간다. (I can't go / I'm unable to go.) — 못 (inability)

**This distinction is critical for Grade 10 exams.** Many Vietnamese learners confuse them.

## Khái Niệm (The Concept)

**안** is placed **between the subject and the verb** to negate:
- **안 + verb = I don't / I won't / I refuse to**

The negation implies **choice, refusal, or determination not to do something**.

## Cấu Trúc (Structure)

### Basic pattern:
```
Subject + 안 + Verb (conjugated)

나는 밥을 안 먹어요.
I don't eat rice. (I choose not to)

Subject + Particle + Object + 안 + Verb

나 = I
는 = topic particle
밥을 = rice (object marker)
안 = negation (choice/refusal)
먹어요 = eat (casual polite)
```

## Quy Tắc (Rules)

**Rule 1: 안 comes before the conjugated verb**
```
안 + -어요 → 안 먹어요
안 + -습니다 → 안 먹습니다
안 + -다 → 안 먹다
```

**Rule 2: The verb still must be conjugated**
```
나는 밥을 안 먹어요. ✓ (verb is conjugated)
나는 밥을 안 먹다. ✗ (dictionary form, not proper speech)
```

**Rule 3: 안 can negate any action verb**
```
안 가다 = not go (choice)
안 하다 = not do (choice)
안 읽다 = not read (choice)
```

## 예제 (Examples)

**Example 1: Simple negation with choice**
```
나는 학교에 안 가요.
(I'm not going to school.) [by choice: I refuse to go]

나 = I
는 = topic marker
학교에 = to school
안 = negation (my choice)
가요 = go
```

**Example 2: Negating an object action**
```
나는 밥을 안 먹어요.
(I don't eat rice.) [by choice: I refuse to eat it]

밥 = rice
을 = object marker
안 = negation
먹어요 = eat
```

**Example 3: Multiple negations in context**
```
나는 한국어를 안 말해요.
(I don't speak Korean.) [by choice, not because I can't]

반대로:
나는 한국어를 못 말해요.
(I can't speak Korean.) [because I don't have the ability]
```

**Example 4: Formal polite with 안**
```
나는 학교에 안 갑니다.
(I am not going to school.) [formal, exam-style]
```

## 흔한 실수 (Common Errors for Vietnamese Learners)

❌ **Mistake 1: Placing 안 after the verb**
- **WRONG:** 나는 먹어요 안. (word order is wrong)
- **CORRECT:** 나는 안 먹어요. (안 comes before conjugated verb)

❌ **Mistake 2: Using 안 with dictionary form verb**
- **WRONG:** 나는 안 먹다. (in actual speech, sounds odd)
- **CORRECT:** 나는 안 먹어요. (proper conjugation)

❌ **Mistake 3: Confusing 안 with 못 (ability negation)**
- **WRONG:** 나는 학교에 안 갔어요 (누군가 나를 막았다면)
- **This sentence implies choice, not inability**
- **If you mean inability (car broke, sick):** 나는 학교에 못 갔어요.

## Mẫu Câu (Sentence Patterns)

**Pattern 1: Simple negation**
```
Subject + 는 + 안 + Verb (-어요/-아요)

나는 안 간다. (I don't go.)
```

**Pattern 2: With object**
```
Subject + 는 + Object + 을/를 + 안 + Verb

나는 밥을 안 먹어요. (I don't eat rice.)
```

**Pattern 3: With location**
```
Subject + 는 + Location + 에 + 안 + Verb

나는 학교에 안 가요. (I don't go to school.)
```

## 요약 (Summary)

**안** is used to negate actions when you **choose not to do something or refuse**:
- 나는 안 간다 = I (choose not to go / I refuse to go)
- 나는 밥을 안 먹어요 = I (choose not to eat rice)

**Position:** 안 comes **directly before the conjugated verb**

**Next lesson:** We'll learn 못, which is the opposite of 안—negation by inability, not choice.
